# 📅 Как работать с этим списком

* Каждый день решай **2–3 задачи** по одной категории.
* Для каждой задачи:

  * сначала **объясни решение словами** (как на интервью),
  * потом **код на Python**,
  * потом проговори **временную/пространственную сложность**.
* В конце 2–3 недели будет крепкая база.
