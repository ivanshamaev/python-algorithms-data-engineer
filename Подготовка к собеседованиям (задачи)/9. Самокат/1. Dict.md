Дан список словарей (List[Dict]), например:

```
[
    {"key1": "value1"},
    {"k1": "v1", "k2": "v2", "k3": "v3"},
    {},
    {},
    {"key1": "value1"},
    {"key1": "value1"},
    {"key2": "value2"}
]
```
Нужно:
- удалить дубликаты словарей
- пустые словари {} считать дубликатами
- сохранить уникальные словари
- порядок не критичен (это важно!)
- сложность не O(n²)

Пример корректного результата:
```
[
    {"key1": "value1"},
    {"k1": "v1", "k2": "v2", "k3": "v3"},
    {"key2": "value2"}
]
```

Главная проблема
❌ dict — нехешируемый, его нельзя положить в set напрямую.
Нужно превратить словарь в хешируемое представление.

Идея решения (ключевая)
Каждый словарь можно:
- Преобразовать в tuple из пар (key, value)
- Отсортировать пары, чтобы порядок ключей не влиял
- Использовать этот tuple как ключ в set

Пример:
```
{"b": 2, "a": 1} → (("a", 1), ("b", 2))
```

Решение на Python:
```
from typing import List, Dict, Any

def remove_duplicates(dicts: List[Dict[Any, Any]]) -> List[Dict[Any, Any]]:
    seen = set()
    result = []

    for d in dicts:
        # Преобразуем словарь в хешируемый вид
        key = tuple(sorted(d.items()))
        
        if key not in seen:
            seen.add(key)
            result.append(d)

    return result
```
Пример использования:
```
data = [
    {"key1": "value1"},
    {"k1": "v1", "k2": "v2", "k3": "v3"},
    {},
    {},
    {"key1": "value1"},
    {"key1": "value1"},
    {"key2": "value2"}
]

print(remove_duplicates(data))
```
