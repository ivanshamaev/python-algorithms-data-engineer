 

Дана целочисленная структура nums, верните все тройки, [nums[i], nums[j], nums[k]]в которых nums[i] + nums[j] + nums[k] == 0, а индексы i, jи kявляются различными.

В выходных данных не должно быть повторяющихся троек. Вы можете вернуть выходные данные и тройки в любом порядке .

Пример 1:
```
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
```

Пояснение:
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
Различные тройки — это [-1,0,1]и [-1,-1,2].

Пример 2:
```
Input: nums = [0,1,1]
Output: []
```
Пояснение: Единственная возможная тройка чисел не дает в сумме 0.

Пример 3:
```
Input: nums = [0,0,0]
Output: [[0,0,0]]
```
Пояснение: Сумма всех трех чисел в этой тройке равна 0.

Ограничения:

3 <= nums.length <= 1000
-10^5 <= nums[i] <= 10^5


Рекомендуемая временная и пространственная сложность
Вам следует стремиться к решению , O(n^2)время и O(1)пространство которого nравны размеру входного массива.


Подсказка 1
Самый простой способ решения — проверить каждую тройку элементов в массиве. Это было бы O(n^3)решением. Можете ли вы предложить лучший способ?


Подсказка 2
Можете ли вы предложить алгоритм после сортировки входного массива? Что можно наблюдать, переставив члены в заданном уравнении?


Подсказка 3
Мы можем перебирать числа по индексу iи получить nums[i] = -(nums[j] + nums[k])после преобразования уравнения, что -nums[i] = nums[j] + nums[k]. Для каждого индекса iмы должны эффективно вычислять пары jи kбез дубликатов. Какой алгоритм подходит для поиска пар jи k?


Подсказка 4
Для эффективного поиска пар " jи k" и "мы" используем подход с двумя указателями для элементов справа от индекса, iпоскольку массив отсортирован. При использовании алгоритма с двумя указателями, рассматриваем jи kкак указатели ( jнаходится слева, kнаходится справа) и target = -nums[i]. Если текущая сумма равна num[j] + nums[k] < target, то нам нужно увеличить значение текущей суммы, увеличив jуказатель. В противном случае, если текущая сумма равна num[j] + nums[k] > target, то нам следует уменьшить значение текущей суммы, уменьшив kуказатель. Как вы поступаете с дубликатами?


Подсказка 5
При вычислении текущей суммы nums[j] + nums[k] == targetдобавьте эту пару к результату. Мы можем перемещаться jили kиспользовать указатель до тех пор , пока j < kпары не повторятся. Это гарантирует, что к результату не будут добавлены повторяющиеся пары.

 

Начало решения:
```
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
```
-----------------------------------

Нужно найти все уникальные тройки чисел:
nums[i] + nums[j] + nums[k] == 0
i ≠ j ≠ k

Важно:
результат без повторяющихся троек
порядок троек не важен
индексы разные
требуется O(n²)


Оптимальное решение (Sort + Two Pointers)
Реализация
```
from typing import List

class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        res = []
        n = len(nums)

        for i in range(n):
            # Пропускаем дубликаты для i
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            target = -nums[i]
            j, k = i + 1, n - 1

            while j < k:
                curr_sum = nums[j] + nums[k]

                if curr_sum == target:
                    res.append([nums[i], nums[j], nums[k]])

                    # Пропускаем дубликаты j
                    while j < k and nums[j] == nums[j + 1]:
                        j += 1
                    # Пропускаем дубликаты k
                    while j < k and nums[k] == nums[k - 1]:
                        k -= 1

                    j += 1
                    k -= 1

                elif curr_sum < target:
                    j += 1
                else:
                    k -= 1

        return res
```

Время
сортировка: O(n log n)
внешний цикл + два указателя: O(n²)
➡️ итог: O(n²)

Память
используется только результат
➡️ O(1) (не считая ответа)
