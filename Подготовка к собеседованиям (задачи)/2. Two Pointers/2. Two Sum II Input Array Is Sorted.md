Мы можем использовать алгоритм двух указателей. Если nums[0] + nums[n-1] > target, то мы знаем, nums[n - 1]что не может быть включен ни в одну пару. Почему? Суть задачи
Дан отсортированный массив numbers (по возрастанию) и число target.
Нужно найти два разных элемента, таких что:
numbers[i] + numbers[j] == target
i < j

Гарантировано:
существует ровно одно решение
нельзя использовать один элемент дважды
требуется O(n) время и O(1) память

Оптимальное решение (Two Pointers)
Идея
left = 0, right = len(numbers) - 1
Пока left < right:
считаем сумму
двигаем нужный указатель

Возвращаем индексы с 1-й индексацией

```
from typing import List

class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:
        left, right = 0, len(numbers) - 1

        while left < right:
            curr_sum = numbers[left] + numbers[right]

            if curr_sum == target:
                # +1 из-за 1-й индексации
                return [left + 1, right + 1]
            elif curr_sum > target:
                right -= 1
            else:
                left += 1
```
Время O(n)
Память O(1)
