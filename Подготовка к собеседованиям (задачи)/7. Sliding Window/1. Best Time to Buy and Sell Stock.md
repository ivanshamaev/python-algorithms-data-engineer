=== Best Time to Buy and Sell Stock ===

 

Вам дан массив целых чисел, pricesгде prices[i]— цена NeetCoin на текущий ithдень.

Вы можете выбрать один день для покупки одного NeetCoin, а другой день в будущем — для его продажи.

Верните максимально возможную прибыль. Вы можете не совершать никаких транзакций , в этом случае прибыль составит 0.

Пример 1:
```
Input: prices = [10,1,5,6,7,1]
Output: 6
```
Пояснение: Покупка prices[1]и продажа prices[4].profit = 7 - 1 = 6

Пример 2:
```
Input: prices = [10,8,7,5,2]
Output: 0
```
Пояснение: Прибыль от сделок невозможна, поэтому максимальная прибыль равна 0.

Ограничения:

1 <= prices.length <= 100
0 <= prices[i] <= 100


Рекомендуемая временная и пространственная сложность
Вам следует стремиться к решению , O(n)время и O(1)пространство которого nравны размеру входного массива.


Подсказка 1
Самым простым решением было бы пройтись по массиву по индексу i, рассматривая его как день покупки, и попробовать все возможные варианты продажи в дни, расположенные справа от индекса i. Это было бы O(n^2)решением. Можете ли вы предложить лучший способ?


Подсказка 2
Покупать следует по определенной цене, а продавать — по более высокой. Можно ли пройтись по массиву по индексу i, рассматривая его либо как цену покупки, либо как цену продажи?


Подсказка 3
Мы можем пройтись по массиву по индексу i, рассматривая его как цену продажи. Но какое значение будет оптимальным для покупки слева от индекса i?


Подсказка 4
Мы пытаемся максимизировать прибыль profit = sell - buy. Если текущая цена i— это цена продажи, мы хотим выбрать минимальную цену покупки слева от этой цены, iчтобы максимизировать прибыль. В результате мы получим максимальную прибыль среди всех вариантов. Однако, если все прибыли отрицательны, мы можем вернуться, 0поскольку нам разрешено пропустить транзакцию.

 

Начало решения:
```
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
```
--------------------------------------

Идея алгоритма
Мы хотим максимизировать:
profit = price_sell - price_buy

Ограничение:
покупка должна быть раньше продажи

Ключевая мысль:
👉 если мы идём слева направо и считаем текущий день как день продажи,
то для максимальной прибыли нам нужен минимальный курс покупки слева.


Реализация (O(n) / O(1))
```
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = float('inf')
        max_profit = 0

        for price in prices:
            if price < min_price:
                min_price = price
            else:
                max_profit = max(max_profit, price - min_price)

        return max_profit
```

Сложность
Время   O(n)
Память  O(1)
