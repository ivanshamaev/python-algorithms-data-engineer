Дан отсортированный массив чисел. Нужно вернуть отсортированный массив квадратов этих чисел. 

Input: nums = [-4, 0, 1, 1, 6, 12, 20]
Output: squares = [0, 1, 1, 36, 144, 400]

Идея

Массив отсортирован, но:
отрицательные числа (если бы были) после возведения в квадрат могут стать большими
поэтому нельзя просто возводить в квадрат и сортировать (O(n log n))
👉 Используем два указателя:
l — слева
r — справа
Сравниваем квадраты и заполняем результат с конца.

-----------------------

Решение за O(n) время и O(n) память
```
class Solution:
    def sorted_squares(self, nums: list[int]) -> list[int]:
        n = len(nums)
        res = [0] * n

        l, r = 0, n - 1
        pos = n - 1

        while l <= r:
            left_sq = nums[l] * nums[l]
            right_sq = nums[r] * nums[r]

            if left_sq > right_sq:
                res[pos] = left_sq
                l += 1
            else:
                res[pos] = right_sq
                r -= 1

            pos -= 1

        return res
```
