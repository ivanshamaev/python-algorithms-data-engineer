=== Reverse Linked List ===

Ты эксперт по Python, есть задача 

Имея начало односвязного списка head, переверните список и верните новое начало списка.

Пример 1:

Input: head = [0,1,2,3]

Output: [3,2,1,0]
Пример 2:

Input: head = []

Output: []
Ограничения:

0 <= The length of the list <= 1000.
-1000 <= Node.val <= 1000


Рекомендуемая временная и пространственная сложность
Вам следует стремиться к решению, которое будет иметь O(n)время и O(1)пространство, равные nдлине заданного списка.


Подсказка 1
Наиболее радикальным решением было бы сохранить значения узлов связанного списка в массиве, затем перевернуть массив, преобразовать его обратно в связанный список и вернуть заголовок нового связанного списка. Это было бы более O(n)трудоемким решением, но потребовало бы дополнительного места. Можете ли вы предложить лучший способ? Возможно, существует подход, позволяющий перевернуть связанный список на месте.


Подсказка 2
Как видите, после переворачивания связанный список становится его концом. Можете ли вы предложить способ изменения ссылок на указатели узлов? Возможно, переворачивание простого списка из двух узлов поможет прояснить этот процесс.


Подсказка 3
Например, рассмотрим список [2, 3], где 2— это начало списка, а 3— его конец. Когда мы перевернём список, 3станет новым началом, и его указатель next будет указывать на 2. Тогда 2указатель next списка будет указывать на null. Сможете ли вы понять, как применить этот подход для переворота связанного списка длиной , nперебирая его элементы?


Подсказка 4
Мы можем развернуть связанный список на месте, поменяв местами указатели между двумя узлами, сохраняя при этом адрес следующего узла. Перед изменением указателя следующего узла необходимо сохранить адрес следующего узла, чтобы не потерять остальную часть списка во время разворота. Таким образом, мы можем безопасно обновить связи между предыдущим и текущим узлами.

--------------------------------

Идея алгоритма
Нужно перевернуть ссылки (next) между узлами, не создавая новых узлов и не используя дополнительную память.

Ключевая мысль:
на каждом шаге мы меняем направление указателя next текущего узла на предыдущий узел.

Итеративное решение (рекомендуемое)
⏱ Время: O(n)
🧠 Память: O(1)

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev = None
        curr = head

        while curr:
            next_node = curr.next   # сохранить следующий узел
            curr.next = prev        # развернуть ссылку
            prev = curr             # сдвинуть prev
            curr = next_node        # перейти дальше

        return prev
