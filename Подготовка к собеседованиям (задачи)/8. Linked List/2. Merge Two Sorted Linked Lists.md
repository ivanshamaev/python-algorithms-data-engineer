=== Merge Two Sorted Linked Lists ===

Ты эксперт по Python, есть задача 

Вам даны заголовки двух отсортированных связанных списков list1и list2.

Объедините два списка в один отсортированный связанный список и верните начало нового отсортированного связанного списка.

Новый список должен состоять из узлов из list1и list2.

Пример 1:



Input: list1 = [1,2,4], list2 = [1,3,5]

Output: [1,1,2,3,4,5]
Пример 2:

Input: list1 = [], list2 = [1,2]

Output: [1,2]
Пример 3:

Input: list1 = [], list2 = []

Output: []
Ограничения:

0 <= The length of the each list <= 100.
-100 <= Node.val <= 100


Рекомендуемая временная и пространственная сложность
Вам следует стремиться к решению, в котором O(n + m)время и O(1)пространство равны , где n— длина list1, а m— длина list2.


Подсказка 1
Решение методом перебора предполагало бы хранение значений обоих связанных списков в массиве, сортировку массива, а затем преобразование его обратно в связанный список. Такой подход потребует O(n)дополнительного места и является тривиальным. Можете ли вы предложить лучший способ? Возможно, можно использовать отсортированную структуру списков.


Подсказка 2
Мы создаём фиктивный узел, чтобы отслеживать начало результирующего связанного списка во время итерации по спискам. Используя l1итераторы l2для list1и list2соответственно, мы проходим по обоим спискам узел за узлом, чтобы построить итоговый связанный список, который также будет отсортирован. Как это реализовать?


Подсказка 3
Например, рассмотрим списки list1 = [1, 2, 3]и list2 = [2, 3, 4]. При итерации по спискам мы перемещаем указатели, сравнивая значения узлов из обоих списков. Мы связываем указатель next итератора с узлом, имеющим меньшее значение. Например, когда l1 = 1и l2 = 2, поскольку l1 < l2, мы указываем указатель next итератора на l1и продолжаем.

Реши ее и ответь на вопросы

Идея алгоритма
Так как оба списка уже отсортированы, мы можем:
идти по ним одновременно
каждый раз выбирать узел с меньшим значением
переподключать существующие узлы, не создавая новых


Итеративное решение (рекомендуемое)
⏱ Время: O(n + m)
🧠 Память: O(1)

class Solution:
    def mergeTwoLists(
        self,
        list1: Optional[ListNode],
        list2: Optional[ListNode]
    ) -> Optional[ListNode]:

        dummy = ListNode(0)
        tail = dummy

        while list1 and list2:
            if list1.val <= list2.val:
                tail.next = list1
                list1 = list1.next
            else:
                tail.next = list2
                list2 = list2.next

            tail = tail.next

        # присоединяем остаток
        tail.next = list1 if list1 else list2

        return dummy.next
