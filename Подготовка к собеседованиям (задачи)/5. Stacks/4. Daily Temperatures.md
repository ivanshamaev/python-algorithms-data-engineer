=== Daily Temperatures ===

 

Вам дан массив целых чисел temperatures, где temperatures[i] представляет собой суточную температуру на данный ith день.

Возвращает массив, result где result[i]— количество дней после ith дня, предшествующего наступлению более теплой температуры в будущем. Если в будущем нет дня, когда ожидается более теплая температура ith, вместо этого устанавливает значение result[i] равным 0.

Пример 1:
```
Input: temperatures = [30,38,30,36,35,40,28]
Output: [1,4,1,2,1,0,0]
```
Пример 2:
```
Input: temperatures = [22,21,20]
Output: [0,0,0]
```
Ограничения:

1 <= temperatures.length <= 1000.
1 <= temperatures[i] <= 100


Рекомендуемая временная и пространственная сложность
Вам следует стремиться к решению, которое будет таким же хорошим или лучше, чем O(n)по времени и O(n)пространству, где n— размер входного массива.


Подсказка 1
Решение методом перебора подразумевало бы итерацию по массиву по индексу iи проверку того, насколько правее находится следующий больший элемент i. Это было бы O(n^2)решением. Можете ли вы предложить лучший способ?


Подсказка 2
Можно ли рассмотреть обратный подход? Например, в [2, 1, 1, 3], следующий больший элемент для чисел [2, 1, 1]— это 3. Вместо проверки каждого элемента по отдельности, можете ли вы придумать способ, при котором, находясь на элементе 3, вы вычисляете результат для элементов [2, 1, 1]? Возможно, здесь найдется полезная структура данных.


Подсказка 3
Мы можем использовать стек для упорядочивания индексов в монотонно убывающем порядке, удаляя элементы из тех индексов, значения которых меньше текущего. Это помогает нам найти результат, используя разницу между индексами и учитывая значения в этих индексах. Видите, как полезен стек?


Подсказка 4
В массиве [2, 1, 1, 3]мы не выполняем никаких операций извлечения элементов во время обработки, [2, 1, 1]поскольку эти элементы уже расположены в порядке убывания. Однако, когда мы достигаем определенного значения 3, мы извлекаем элементы из стека до тех пор, пока верхний элемент стека не станет меньше текущего элемента. Для каждого извлеченного элемента мы вычисляем разницу между индексами и сохраняем ее в позиции, соответствующей извлеченному элементу.

 

Начало решения:
```
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
```
----------------------------

Идея алгоритма
Для каждого дня нужно узнать:
через сколько дней температура станет строго больше

Ключевая мысль:
👉 следующий больший элемент справа

Чтобы не делать O(n²), используем монотонно убывающий стек индексов.

Оптимальное решение (монотонный стек)
⏱ Время: O(n)
🧠 Память: O(n)
```
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        result = [0] * n
        stack = []  # стек индексов

        for i in range(n):
            while stack and temperatures[i] > temperatures[stack[-1]]:
                prev_day = stack.pop()
                result[prev_day] = i - prev_day

            stack.append(i)

        return result
```
