Ты эксперт по Python, есть задача Допустимые скобки

Вам дана строка, sсостоящая из следующих символов: '(', ')', '{', '}', '['и ']'.

Входная строка sдействительна тогда и только тогда, когда:

Каждый открытый кронштейн закрывается кронштейном того же типа.
Открытые скобки закрываются в правильном порядке.
Каждой закрывающей скобке соответствует открывающая скобка того же типа.
Возвращает true, trueесли sстрока допустима, и falsefalse в противном случае.

Пример 1:

Input: s = "[]"

Output: true
Пример 2:

Input: s = "([{}])"

Output: true
Пример 3:

Input: s = "[(])"

Output: false
Пояснение: скобки закрыты не в правильном порядке.

Ограничения:

1 <= s.length <= 1000


Реши ее и ответь на вопросы

Подсказка 1
Решение методом перебора заключалось бы в непрерывном удалении допустимых скобок до тех пор, пока их больше нельзя будет удалить. Если оставшаяся строка пуста, вернуть true; в противном случае — false. Это привело бы к решению O(n^2). Можем ли мы придумать лучший подход? Возможно, структура данных могла бы помочь.


Подсказка 2
Для хранения символов можно использовать стек. Проходим по строке по индексу. Открывающую скобку помещаем в стек. Если скобка является закрывающей, проверяем наличие соответствующей открывающей скобки на вершине стека. Если соответствующей открывающей скобки не найдено, немедленно возвращаем false. Почему это работает?


Подсказка 3
В допустимом выражении в скобках каждая открывающая скобка должна иметь соответствующую закрывающую скобку. Стек используется для обработки допустимой строки и должен быть пустым после завершения всего процесса. Это гарантирует наличие допустимой подстроки между каждой открывающей и закрывающей скобкой.

Идея задачи

Нужно проверить, что строка:
содержит корректные пары скобок
порядок вложенности правильный
каждой закрывающей соответствует последняя открывающая
➡️ Это поведение LIFO → идеально подходит стек


Оптимальное решение (Stack) 
Реализация

class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        pairs = {
            ')': '(',
            '}': '{',
            ']': '['
        }

        for char in s:
            # Если открывающая — кладём в стек
            if char in pairs.values():
                stack.append(char)
            else:
                # Закрывающая скобка
                if not stack or stack[-1] != pairs[char]:
                    return False
                stack.pop()

        # Стек должен быть пустым
        return not stack



⏱ Сложность
Время O(n)
Память O(n)
