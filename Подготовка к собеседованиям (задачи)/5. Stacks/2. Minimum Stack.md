Подсказка 1
Самым простым решением было бы всегда проверять минимальный элемент в стеке для getMin()вызова функции. Это был бы один из O(n)подходов. Можете ли вы предложить лучший способ? Возможно, O(n)дополнительное пространство для хранения некоторой информации.


Подсказка 2
Для хранения элементов можно использовать стек. Но как найти минимальный элемент в любой момент времени? Возможно, стоит рассмотреть префиксный подход.


Подсказка 3
Мы используем дополнительный стек для поддержания префиксного минимального элемента. При удалении элементов из основного стека следует также удалять элементы из этого дополнительного стека. Идея задачи
Нужно реализовать стек, который кроме обычных операций умеет мгновенно возвращать минимальный элемент.
❌ Просто искать min(stack) нельзя — это O(n)
✅ Нужно хранить минимум заранее

Реализация (O(1) все операции)
```
class MinStack:

    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val: int) -> None:
        self.stack.append(val)
        if not self.min_stack:
            self.min_stack.append(val)
        else:
            self.min_stack.append(min(val, self.min_stack[-1]))

    def pop(self) -> None:
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]
```
