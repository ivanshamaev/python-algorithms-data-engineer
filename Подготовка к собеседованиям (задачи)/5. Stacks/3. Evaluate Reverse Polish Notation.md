=== Evaluate Reverse Polish Notation ===

 

Вам предоставлен массив строк tokens, представляющих допустимое арифметическое выражение в обратной польской нотации .

Верните целое число, представляющее результат вычисления выражения.

В качестве операндов могут выступать целые числа или результаты других операций.
В число операторов входят '+', '-', '*', и '/'.
Предположим, что деление целых чисел всегда приводит к округлению до нуля.
Пример 1:
```
Input: tokens = ["1","2","+","3","*","4","-"]
Output: 5
```
Explanation: 
```
((1 + 2) * 3) - 4 = 5
```
Ограничения:

1 <= tokens.length <= 1000.
tokens[i] — это "+", "-", "*", или "/", или строка, представляющая целое число в диапазоне [-100, 100].


Рекомендуемая временная и пространственная сложность
Вам следует стремиться к решению , O(n)время и O(n)пространство которого nравны размеру входного массива.


Подсказка 1
Решение методом перебора подразумевало бы многократный поиск оператора + - * /в массиве и модификацию массива путем вычисления результата для этого оператора и двух операндов слева от него. Это было бы O(n^2)решением. Можете ли вы предложить лучший способ? Возможно, мы можем использовать структуру данных для эффективной обработки операций.


Подсказка 2
Мы можем использовать стек. Мы перебираем массив, и если встречаем число, помещаем его в стек. Если встречаем оператор, извлекаем два элемента из стека, рассматриваем их как операнды и решаем уравнение, используя текущий оператор. Затем помещаем результат обратно в стек. Почему это работает?


Подсказка 3
Поскольку массив имеет постфиксное выражение, стек помогает нам поддерживать правильный порядок операций, гарантируя, что при выполнении операции мы всегда используем самые последние операнды (те, которые ближе всего к оператору). После итерации окончательный результат остается в стеке.

 

Начало решения:
```
class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
```
-------------------------------

Идея решения
Обратная польская нотация (postfix) означает:
оператор всегда применяется к двум предыдущим операндам
скобки не нужны
порядок вычислений однозначен
👉 Следовательно, стек — идеальная структура данных.


Реализация
```
class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        stack = []

        for token in tokens:
            if token not in {"+", "-", "*", "/"}:
                stack.append(int(token))
            else:
                b = stack.pop()
                a = stack.pop()

                if token == "+":
                    stack.append(a + b)
                elif token == "-":
                    stack.append(a - b)
                elif token == "*":
                    stack.append(a * b)
                else:  # "/"
                    stack.append(int(a / b))  # округление к нулю

        return stack[0]
```
⏱ Сложность
Время: один проход → O(n)
Память: стек → O(n)
