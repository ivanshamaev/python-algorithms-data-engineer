Ты эксперт по Python, есть задача


Дан массив целых чисел nums и целое число target. Верните индексы i и j такие, что nums[i] + nums[j] == target и i != j.

Можно предположить, что каждый входной параметр имеет ровно одну пару индексов i, j удовлетворяющих условию.

Верните ответ, начав с элемента с меньшим индексом.

Пример 1:
```
Input: 
nums = [3,4,5,6], target = 7
Output: [0,1]
```
Пояснение: nums[0] + nums[1] == 7, поэтому мы возвращаемся [0, 1].

Пример 2:
```
Input: nums = [4,5,6], target = 10
Output: [0,2]
```
Пример 3:
```
Input: nums = [5,5], target = 10
Output: [0,1]
```
Ограничения:
2 <= nums.length <= 1000
-10,000,000 <= nums[i] <= 10,000,000
-10,000,000 <= target <= 10,000,000
Существует только один правильный ответ.


Рекомендуемая временная и пространственная сложность
Вам следует стремиться к решению, O(n)время и O(n)пространство которого соответствуют размеру входного массива, где n — размер этого массива.


Подсказка 1
Решение методом перебора заключалось бы в проверке каждой пары чисел в массиве. Это было бы O(n^2)решением. Можете ли вы предложить лучший способ? Возможно, в виде математического уравнения?


Подсказка 2
Дано: Нам нужно найти индексы iи jтакие, что i != jи nums[i] + nums[j] == target. Можете ли вы перегруппировать уравнение и попытаться выбрать любой индекс для итерации?


Подсказка 3
Мы можем перебирать числа по индексу i. Пусть difference = target - nums[i]и проверяем, differenceсуществует ли элемент в хэш-карте по мере итерации по массиву, в противном случае сохраняем текущий элемент в хэш-карте с его индексом и продолжаем. Мы используем хэш-карту для O(1)поиска.

Решение:

Суть задачи
Нужно найти два разных индекса i и j, такие что:

nums[i] + nums[j] == target

Гарантировано:
решение ровно одно
нужно вернуть индексы в порядке возрастания


Реализация:
```
from typing import List

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}  # число -> индекс

        for i, num in enumerate(nums):
            diff = target - num

            if diff in seen:
                return [seen[diff], i]

            seen[num] = i
```
