Ты эксперт по Python, есть задача


Даны две строки sи t. Верните значение, true если эти две строки являются анаграммами друг друга, в противном случае верните значение false.

Анаграмма — это строка, содержащая те же самые символы , что и другая строка, но порядок символов может отличаться.

Пример 1:

Input: s = "racecar", t = "carrace"
Output: true

Пример 2:

Input: s = "jar", t = "jam"
Output: false

Ограничения:

s и t состоят из строчных английских букв.

Рекомендуемая временная и пространственная сложность
Вам следует стремиться к решению, в котором O(n + m) время и O(1) пространство равны , где n — длина строки s, а m — длина строки t.

Подсказка 1
Самым простым решением было бы отсортировать заданные строки и проверить их на равенство. Это было бы O(nlogn + mlogm)решением. Хотя это решение приемлемо, можете ли вы предложить лучший способ без сортировки заданных строк?

Подсказка 2
Согласно определению анаграммы, мы можем переставить символы. Имеет ли значение порядок символов в обеих строках? Тогда что же имеет значение?

Подсказка 3
Мы можем просто отслеживать частоту каждого символа. Для этого мы можем использовать две отдельные хеш-таблицы для двух строк. Затем мы можем проверить, sсовпадает ли частота каждого символа в строке с частотой в другой строке tи наоборот.

Реши ее и ответь на вопросы (решить можно разными вариантами)

Решение 1:
Идея
Если длины строк разные → не анаграммы
Создаём массив из 26 нулей
Увеличиваем счётчик для s
Уменьшаем счётчик для t
В конце все значения должны быть равны 0

Сложность
⏱ Время: O(n + m)
💾 Память: O(1) (26 элементов)

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False

        freq = [0] * 26

        for c in s:
            freq[ord(c) - ord('a')] += 1

        for c in t:
            freq[ord(c) - ord('a')] -= 1

        for count in freq:
            if count != 0:
                return False

        return True


Решение 2:
Идея
Считаем частоты в s
Уменьшаем при проходе по t
Если символа нет или счётчик ушёл в минус → False

Сложность
⏱ Время: O(n + m)
💾 Память: O(1) (максимум 26 ключей)

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False

        count = {}

        for c in s:
            count[c] = count.get(c, 0) + 1

        for c in t:
            if c not in count or count[c] == 0:
                return False
            count[c] -= 1

        return True
