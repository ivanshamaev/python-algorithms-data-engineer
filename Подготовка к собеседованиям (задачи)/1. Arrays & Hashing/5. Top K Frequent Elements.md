Тестовые примеры генерируются таким образом, что ответ всегда уникален.

Вы можете вернуть результат в любом порядке.

Пример 1:
Input: nums = [1,2,2,3,3,3], k = 2
Output: [2,3]

Пример 2:
Input: nums = [7,7], k = 1
Output: [7]

Ограничения:
1 <= nums.length <= 10^4.
-1000 <= nums[i] <= 1000
1 <= k <= number of distinct elements in nums.

Суть задачи
Дан массив nums и число k.
Нужно вернуть k наиболее часто встречающихся элементов.

Важно:
ответ гарантированно уникален
порядок результата любой
требуется O(n) время и O(n) память


Оптимальное решение (Bucket Sort)
Идея
Посчитать частоты элементов
Создать массив корзин, где индекс = частота
Разложить числа по корзинам
Идти с конца и собрать k элементов


Реализация:
from typing import List
from collections import defaultdict

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        # 1. Частоты
        freq = defaultdict(int)
        for num in nums:
            freq[num] += 1

        # 2. Корзины: индекс = частота
        buckets = [[] for _ in range(len(nums) + 1)]

        # 3. Раскладываем числа по корзинам
        for num, count in freq.items():
            buckets[count].append(num)

        # 4. Собираем k самых частых
        res = []
        for i in range(len(buckets) - 1, 0, -1):
            for num in buckets[i]:
                res.append(num)
                if len(res) == k:
                    return res

Сложность:
Время: O(n)
Память: O(n)
