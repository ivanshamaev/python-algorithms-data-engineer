Начало решения:

```
class Solution:

    def encode(self, strs: List[str]) -> str:

    def decode(self, s: str) -> List[str]:
```

-----------------------------

Суть задачи
Нужно:
encode: превратить List[str] → str
decode: восстановить str → List[str]
⚠️ Ограничение:
Строки могут содержать ЛЮБЫЕ ASCII-символы (включая #, цифры, \0, и т.д.)
➡️ значит разделители как символы использовать нельзя напрямую.


⏱ Сложность
Пусть:
m — сумма длин всех строк
n — количество строк

Encode
⏱ O(m)
💾 O(m)

Decode
⏱ O(m + n)
💾 O(n)

Реализация - encode
```
from typing import List

class Solution:

    def encode(self, strs: List[str]) -> str:
        encoded = []
        for s in strs:
            encoded.append(f"{len(s)}#{s}")
        return "".join(encoded)


    def decode(self, s: str) -> List[str]:
        res = []
        i = 0

        while i < len(s):
            # читаем длину
            j = i
            while s[j] != '#':
                j += 1

            length = int(s[i:j])
            j += 1  # пропускаем '#'

            # читаем строку длины length
            res.append(s[j:j + length])

            i = j + length

        return res
```
