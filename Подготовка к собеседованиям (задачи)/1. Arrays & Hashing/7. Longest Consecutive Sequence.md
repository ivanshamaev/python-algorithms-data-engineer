 "Самая длинная последовательность"

Дана последовательность целых чисел nums. Верните длину самой длинной последовательной последовательности элементов, которую можно составить.

Последовательность элементов — это последовательность, в которой каждый элемент ровно больше 1 предыдущего. Элементы не обязательно должны быть последовательными в исходном массиве.

Вам необходимо написать алгоритм, который работает за O(n) время .

Пример 1:
```
Input: nums = [2,20,4,10,3,4,5]
Output: 4
```
Пояснение: Самая длинная непрерывная последовательность — это [2, 3, 4, 5].

Пример 2:
```
Input: nums = [0,3,2,5,4,6,1,1]
Output: 7
```
Ограничения:
0 <= nums.length <= 1000
-10^9 <= nums[i] <= 10^9

Рекомендуемая временная и пространственная сложность
Вам следует стремиться к решению, которое будет таким же хорошим или лучше, чем O(n)по времени и O(n)пространству, где n— размер входного массива.


Подсказка 1
Простейшее решение заключалось бы в том, чтобы рассматривать каждый элемент массива как начало последовательности и подсчитывать длину последовательности, образованной с этим начальным элементом. Это было бы O(n^2)решением. Можете ли вы предложить лучший способ?


Подсказка 2
Есть ли способ определить начало последовательности? Например, в [1, 2, 3, 10, 11, 12], только 1и 10являются началом последовательности. Вместо того чтобы пытаться составить последовательность для каждого числа, следует рассматривать только такие числа, как 1и 10.


Подсказка 3
Мы можем считать число numначалом последовательности тогда и только тогда, когда оно num - 1отсутствует в заданном массиве. Мы перебираем массив и начинаем строить последовательность только в том случае, если это число является началом последовательности. Это позволяет избежать повторной работы. Для O(1)поиска можно использовать хеш-множество, преобразовав массив в хеш-множество.

Она проверяет умение думать про O(n) и правильно использовать hash set.

Идея
Преобразовать массив в set
Для каждого числа:
если num - 1 нет в set → это начало
считать длину последовательности num, num+1, num+2...
Запоминать максимальную длину

Реализация:
```
from typing import List

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        num_set = set(nums)
        longest = 0

        for num in num_set:
            # Проверяем, является ли num началом последовательности
            if num - 1 not in num_set:
                current = num
                length = 1

                # Строим последовательность
                while current + 1 in num_set:
                    current += 1
                    length += 1

                longest = max(longest, length)

        return longest
```
⏱ Сложность
Время
Преобразование в set → O(n)
Каждый элемент посещается один раз
➡️ O(n)

Память
Hash set → O(n)
