=== Binary Search ===

 Бинарный поиск

Вам дан массив различных целых чисел nums, отсортированных в порядке возрастания, и целое число target.

Реализуйте функцию для поиска targetвнутри nums. Если он существует, верните его индекс, в противном случае — -1.

Ваше решение должно работать в О(лог н) O(log n) время.

Пример 1:
```
Input: nums = [-1,0,2,4,6,8], target = 4
Output: 3
```
Пример 2:
```
Input: nums = [-1,0,2,4,6,8], target = 3
Output: -1
```
Ограничения:

1 <= nums.length <= 10000.
-10000 < nums[i], target < 10000
Все целые числа в numsявляются уникальными .


Рекомендуемая временная и пространственная сложность
Вам следует стремиться к решению , O(logn)время и O(1)пространство которого nравны размеру входного массива.


Подсказка 1
Можно ли найти алгоритм, полезный, когда массив отсортирован? Возможно, кроме линейного поиска.


Подсказка 2
Название задачи — это название алгоритма, который мы можем использовать. Нам нужно найти целевое значение, и если его нет в массиве, вернуть его -1. У нас есть lи rв качестве границ сегмента массива, в котором мы ищем. Попробуйте составить условия, чтобы исключать половину сегмента поиска на каждом шаге. Возможно, отсортированная структура массива может быть полезной.


Подсказка 3
Мы сравниваем целевое значение с значением midсегмента. Например, рассмотрим массив [1, 2, 3, 4, 5]и target = 4. midЗначение равно 3, следовательно, на следующей итерации мы ищем справа от mid. Оставшийся сегмент — [4,5]. Почему?


Подсказка 4
Поскольку массив отсортирован, все элементы слева от mid(включая 3) гарантированно будут меньше целевого значения. Следовательно, мы можем смело исключить эту половину массива из рассмотрения, сузив поиск до правой половины, и повторять этот поиск до тех пор, пока не найдем целевое значение.

 

Начало решения:
```
class Solution:
    def search(self, nums: List[int], target: int) -> int:
```

--------------------------------

Идея алгоритма
Так как массив:
отсортирован
элементы уникальны
мы можем на каждом шаге отбрасывать половину массива, сравнивая target с серединным элементом.
Это и даёт сложность O(log n).

Реализация (итеративная, O(1) память)
```
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        l, r = 0, len(nums) - 1

        while l <= r:
            mid = (l + r) // 2

            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                l = mid + 1
            else:
                r = mid - 1

        return -1
```
Сложность
Время O(log n)
Память O(1)
