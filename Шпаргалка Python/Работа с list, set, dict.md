Полный и структурированный справочник по **добавлению, изменению и удалению элементов** в `list`, `set` и `dict`. 

## 📌 `list` (упорядоченный, изменяемый, допускает дубликаты)

### ➕ Добавление

```python
lst = [1, 2, 3]

lst.append(4)              # в конец
lst.extend([5, 6])         # добавить несколько
lst.insert(1, 100)         # по индексу
lst += [7, 8]              # расширение
lst[len(lst):] = [9, 10]   # через срез
```

### ✏️ Изменение

```python
lst[0] = 999               # по индексу
lst[1:3] = [10, 20]        # замена среза
lst[:] = [1, 2, 3]         # полная замена
```

### ➖ Удаление

```python
lst.pop()                  # последний элемент
lst.pop(1)                 # по индексу
lst.remove(2)              # по значению (первое вхождение)
del lst[0]                 # по индексу
del lst[1:3]               # диапазон
lst.clear()                # очистить список
```


## 📌 `set` (неупорядоченный, уникальные элементы)

### ➕ Добавление

```python
s = {1, 2, 3}

s.add(4)                   # один элемент
s.update([5, 6])           # несколько
s |= {7, 8}                # объединение
```

### ✏️ Изменение

⚠️ **Нельзя изменить элемент напрямую**
Только удалить и добавить заново:

```python
s.remove(3)
s.add(30)
```

### ➖ Удаление

```python
s.remove(2)                # ошибка, если элемента нет
s.discard(10)              # без ошибки
s.pop()                    # случайный элемент
s.clear()                  # очистить
```

## 📌 `dict` (ключ → значение)

### ➕ Добавление

```python
d = {"a": 1}

d["b"] = 2                 # новый ключ
d.update({"c": 3})         # несколько
d.setdefault("d", 4)       # если ключа нет
```

### ✏️ Изменение

```python
d["a"] = 100               # по ключу
d.update({"a": 200})       # массово
```

### ➖ Удаление

```python
d.pop("a")                 # по ключу
d.pop("x", None)           # без ошибки
del d["b"]                 # по ключу
d.clear()                  # очистить
```

## 🧠 Краткая таблица

| Тип  | Добавить               | Изменить           | Удалить          |
| ---- | ---------------------- | ------------------ | ---------------- |
| list | append, insert, extend | `lst[i] = x`, срез | pop, remove, del |
| set  | add, update            | ❌ нельзя           | remove, discard  |
| dict | `d[k]=v`, update       | `d[k]=v`           | pop, del         |
